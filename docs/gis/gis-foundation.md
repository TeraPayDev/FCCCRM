# CRAM GIS Foundation

Milestone 8 uses PostGIS as the spatial system of record, GeoServer as the publication service, and MapLibre in the React client. `GeographicArea` supports parent linkage, code, name, type, geometry, centroid, and metadata. `SpatialLayer` links published-layer metadata to dataset versions when available.

The acceptance seed is deliberately synthetic and marked non-authoritative. It exists only to prove storage, spatial filtering, API serialization, GeoServer connectivity/publication, and MapLibre interaction. It must not be interpreted as an official Freetown planning block, catchment, ward, community, or approved CRS hierarchy. Authoritative hierarchy and CRS decisions remain deferred until source data is confirmed.
